Notebook

Worked examples from a set of handwritten counterpoint notebooks, transcribed so they can be seen and heard. Each one names the notebook page it comes from and quotes the note written beside it. Some spots in the pencil were hard to read; the captions say where. More pages, two-voice and three-voice, are on the way.
